# A² Golf downloads

Golf sim software for Windows. **Download the newest version from
[Releases](https://github.com/apashton/Golf-Sim-releases/releases/latest)**:
`A-Squared-Golf-Setup-<version>.exe` under Assets, then run it. Once
installed, it keeps itself up to date.

- The website: https://apashton.github.io/Golf-Sim-releases/
- Help, a problem or an idea: [Issues](https://github.com/apashton/Golf-Sim-releases/issues).
  In the game, Menu → System → Feedback saves a report and opens this page for you.

The *Source code* links on each release are added by GitHub itself. They
hold only this repository's files: this page and the website. The game's
own code isn't published here.
